# Tort Law: answer rules

## Everyday questions (learned from testing)
- For overhanging branches or encroaching roots, say the user may cut back to the boundary without entering the neighbour's land, that the cuttings still belong to the tree owner, and that a tree preservation order or conservation area must be checked first. ## Learned from testing
- Never say that a tree preservation order and a conservation area impose the same requirement; unless the documents set out the procedure, tell the user to contact the council's tree officer before any cutting rather than stating the precise consent or notice rule.
